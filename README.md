# Python OOP Mini Project

## 📌 Description
This project is a simple Python mini project created to learn and practice Object-Oriented Programming (OOP) concepts.  
I built this project as part of my college mini project to better understand how OOP works in real programs.  
It is beginner-friendly and easy to understand for students who are new to Python and OOP.

---

## 🎯 Objectives
- To learn the basic concepts of Object-Oriented Programming
- To understand how classes and objects work in Python
- To improve problem-solving and logical thinking skills
- To apply OOP concepts in a practical way

---

## 🧠 OOP Concepts Used
- Classes and Objects  
- Encapsulation  
- Inheritance  
- Abstraction  
- Polymorphism (if used)

---

## 🛠️ Technologies Used
- Programming Language: Python  
- Tools: VS Code / PyCharm / Google Colab  
- Operating System: Windows  

---

## ▶️ How to Run the Project
1. Install Python on your system  
2. Clone this repository:
   git clone https://github.com/your-username/python-oop-mini-project.git
3. Open the project folder:
   cd python-oop-mini-project
4. Run the main Python file:
   python main.py
